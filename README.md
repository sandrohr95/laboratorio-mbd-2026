**Web con las diapositivas:** https://sandrohr95.github.io/laboratorio-mbd-2026

## Cómo usar este repositorio

```bash
git clone https://github.com/sandrohr95/laboratorio-mbd-2026.git   # la primera vez
git pull                    # antes de cada clase
```

Trabaja en tu propia carpeta o en tu propio repositorio. Si modificas los archivos de este, `git pull` dará conflictos.
